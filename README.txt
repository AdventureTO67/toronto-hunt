TORONTO HUNT PAGES

1. Place T001.png through T030.png inside the images folder.
2. Upload the CONTENTS of this folder to the root of your GitHub Pages repository.
3. Each random folder contains an index.html mapped to its corresponding PNG.
4. Example: /f7k3m9/ displays /images/T001.png.
5. Filenames are case-sensitive on GitHub Pages.

See PATH_MAPPING.csv for all 30 mappings.
